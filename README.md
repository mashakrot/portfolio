# Personal Portfolio

## <a name="introduction">Introduction</a>

A pixel-art gamified personal portfolio built with **React** and **Vite**. Explore  my projects, experience, education, and interests by walking around interactive rooms to learn more.

Check it out here 👉 [Portfolio](https://mashakrot.github.io/portfolio/)

1. [Tech Stack](#tech-stack)
2. [Features](#features)

## <a name="tech-stack">Tech Stack</a>

- React
- Vite
- JavaScript
- CSS
- Spotify Web Playback SDK

## <a name="features">Features</a>

👉 **Interactive pixel-art room** – move around the room and click on objects to explore the portfolio.

👉 **Retro desktop interface** – browse About, Projects, Experience, Education, and Contact through old-school popup screens.

👉 **Projects** – check out machine learning, data analytics, as well as web development and animation projects, along with their tools and links.

👉 **Spotify player** – easily connect Spotify and listen to my personal playlist while exploring
